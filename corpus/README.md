# 命理古籍语料（corpus）

本目录用于收集八字 / 命理相关的古代文献原文，目的是拿到**非 PDF、可解析**的纯文本，
方便做检索、RAG 或训练语料。

## 数据来源

统一使用 **维基文库（[zh.wikisource.org](https://zh.wikisource.org)）**：

- 这些古籍均属**公有领域**文献，可合法获取。
- 维基文库提供 API 原文（wikitext），经脚本清洗后得到干净的纯文本，**不是 PDF**，
  解析/分词/入库都很方便。
- 命令行 `--out` 指定的目录下会生成 `<书名>.txt`（UTF-8）。

## 使用方法

传输层优先调用系统自带的 **curl**（macOS / Linux 均预装），未找到 curl 时回退到
Python 标准库 `urllib`。**无需 `pip install`**。需要能访问外网（维基文库）。

```bash
cd corpus
python3 fetch_mingli_classics.py                 # 下载全部，输出到 ./books
python3 fetch_mingli_classics.py --out mydir    # 指定输出目录
python3 fetch_mingli_classics.py --only 神峰通考 三命通会   # 只下指定的
python3 fetch_mingli_classics.py --list          # 只列出将要下载的条目

# 走 SOCKS5 代理（如本机 v2ray 的 10808 端口）：
python3 fetch_mingli_classics.py --proxy socks5://127.0.0.1:10808
# 也可不传 --proxy，改用环境变量： export SOCKS_PROXY=socks5://127.0.0.1:10808
```

> 注意：维基文库(Wikimedia) 对匿名 / 共享代理 IP 有**限流(HTTP 429)**。
> 脚本已内置礼貌间隔与 429 指数退避重试；若仍频繁 429，请放慢节奏或换更干净的出口 IP。

### 维基文库暂无独立条目（需其它来源）

你提到的这几本在维基文库里没有独立页面，主脚本 `fetch_mingli_classics.py`
**不会**下载它们。其中《滴天髓阐微》已用专用脚本抓下（见下），其余建议来源：

- **滴天髓阐微（已下载✅）**：清·沈孝瞻 原著、徐乐吾(任铁樵) 评注。
  维基文库无此条目，改用**古诗文网/古文岛**
  (`https://www.gushiwen.cn/guwen/book_74c064ea85bf.aspx`) 抓取。
  专用脚本：`fetch_ditiansui.py`（抓 64 章并清洗），
  若抓回的原文带站点导航垃圾，再用 `clean_ditiansui.py` 二次清洗。
  成品：`books/滴天髓阐微.txt`（约 13.8 万字，含诗诀 + 【原注】+【任氏曰】+ 命例）。
- **子平真诠**：可在「中国哲学书电子化计划」<https://ctext.org> 检索。
- **千里命稿 / 八字提要**：韦千里等民国著作，多见于各古籍 PDF 合集或
  古诗文网全文页（均为 HTML，可参照 `fetch_ditiansui.py` 思路再补解析分支）。
- **天元巫咸经**（你写的「天元咸巫」应为「天元巫咸经」）：
  常收在《古今图书集成·艺术典·星命部》，维基文库有
  `欽定古今圖書集成/博物彙編/藝術典/星命部` 这一大条目，可在其中定位。

> 备注：你最初提到的《天元咸巫》应是笔误，正确书名为《天元巫咸经》。

### 辅助脚本

- `fetch_ditiansui.py`：从古诗文网抓《滴天髓阐微》全文（64 章），支持
  `--proxy socks5://127.0.0.1:10808`、断点续传（按已落盘章节跳过）。
- `clean_ditiansui.py`：对已抓回、但混有站点导航垃圾的文件做二次清洗，
  去掉「古文岛」指纹头、「注释 译文」标签、章节导航与下一章预览，保留
  诗诀 + 【原注】 + 【任氏曰】 + 命例。

> 注意：古诗文网/古文岛对频繁请求会返回空壳页或限流，若抓取中断，
> 等限流恢复后用 `--proxy` 重跑即可（断点续传会自动跳过已抓章节）。

## 说明

- 若本机命令行直连无外网、但装有 v2ray 等代理（如 SOCKS5 在 `127.0.0.1:10808`），
  用 `--proxy socks5://127.0.0.1:10808` 即可；脚本已实测在该环境下把 6 本全部抓下。
- 若需要把「未在维基文库」的几本也自动化抓取，可基于 `fetch_mingli_classics.py`
  的 `fetch_raw` / `clean` 思路，针对古诗文网等来源再补一个 HTML 解析分支。
